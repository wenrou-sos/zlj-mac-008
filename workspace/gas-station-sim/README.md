# 加油站高峰车道疏导模拟器

站长输入分时段到站车流、油品偏好、油枪配置与员工数量，模拟排队演化，
输出员工调度方案与可解释的疏导建议。

## 功能

- **离散事件模拟（DES）**：车辆到达（分时段泊松过程）、加油服务（三角分布）、
  事件堆驱动，逐分钟采样系统状态
- **油品车道分流**：每种油品一条 FIFO 等待车道，油枪声明兼容油品，
  空闲油枪从兼容车道拉取等待最久的车辆
- **动态增开服务位**：备用油枪在排队超过阈值（辆数或最久等待）时自动增开、
  空闲超时自动关闭；员工是共享资源，人手不足时无法增开并记录告警
- **结果可解释**：每一次开/关枪、人力不足、长等待都写入事件日志并附触发原因；
  输出 15 分钟粒度人力需求、油枪开闭甘特图、等待分布与调度建议
- **方案对比**：连续两次模拟的 KPI 自动并排对比（▲▼ vs 上次）

## 快速开始

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
python3 -m uvicorn app.main:app --port 8000

# 前端（Node 18+，另开一个终端）
cd frontend
npm install
npm run dev        # 开发模式 http://localhost:5173（代理 /api 到 8000）

# 或构建后由后端统一托管
npm run build      # 之后访问 http://localhost:8000
```

## 项目结构

```
backend/
  app/models.py   # 配置与结果的 Pydantic 模型
  app/engine.py   # 离散事件模拟引擎（事件堆 + 策略巡检）
  app/presets.py  # 预设场景：工作日早高峰 / 周末平峰 / 柴油夜高峰
  app/main.py     # FastAPI：/api/presets、/api/simulate、托管前端
frontend/
  src/components/ # 配置面板、KPI、排队图、人力图、油枪甘特图、事件日志等
```

## 模型说明

| 要素 | 建模方式 |
|---|---|
| 到站车流 | 分时段泊松到达，各油品独立速率（辆/小时） |
| 加油时间 | 三角分布（最小/常见/最大），按油品区分（柴油重卡更慢） |
| 车道 | 每油品一条 FIFO 等待池，车辆不可跨油品换道 |
| 油枪 | 兼容若干油品；`常开` 全程在线，`备用` 由策略动态开闭 |
| 员工 | 共享资源：并发服务数 ≤ 员工数 × 每人照看枪数 |
| 增开策略 | 车道排队 ≥ 阈值 或 最久等待 ≥ 阈值，且有人力余量时增开 |
| 关闭策略 | 备用枪连续空闲超过阈值自动关闭，释放人力 |

## API

- `GET /api/presets` — 预设场景列表
- `POST /api/simulate` — 提交 `SimConfig`，返回 KPI、时间序列、
  油枪开闭区间、人力需求桶、事件日志与调度建议
